# liulao-space.github.io

Personal site: **Vibe Coding** engineering logs + frontend knowledge cards.

- Site: https://liulao-space.github.io
- Stack: VitePress

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Teaching monorepo demo

```bash
cd examples/mini-monorepo
pnpm install
pnpm dev:admin
pnpm dev:www
```
