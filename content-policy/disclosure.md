# 公开边界（写稿约束 · 不对外展示）

本文件只约束「如何写日志」，**不作为站点页面发布**。

本站内容来自工作与学习中的工程实践，但**不等于公开公司项目**。

## 可以公开

- 通用工程概念与模式（monorepo、workspace、SSR、共享配置）
- 改写后的教学示例与虚构项目名
- 可复制的命令、目录结构示意、踩坑清单
- 「如果从零搭建，我会多做什么」这类对比结论
- 自己的 Code Review 笔记（对事不对人）

## 禁止公开

- 真实仓库名、包名、内部品牌与产品名
- 域名、租户、客户、未公开业务功能
- Token、密钥、内网地址、部署脚本中的敏感信息
- 可还原业务的接口路径、页面文案、数据字段
- 同事真实姓名（可用「同事」）
- 公司源码整段搬运

## 脱敏映射（写作时固定）

公开文章使用教学名，例如：

| 角色 | 公开名 |
|------|--------|
| monorepo 根 | `learnspace` |
| 管理端 SPA | `apps/admin` |
| 对外门户 | `apps/www` |
| 共享样式包 | `@learnspace/unocss-config` |

## 发布前自检

- [ ] 全文搜索无真实公司/产品/域名
- [ ] 无 token、key、内网 IP
- [ ] 配图标签也是教学名
- [ ] 代码片段是最小可演示示例，不是业务逻辑
- [ ] 区分「事实 / 我的理解 / 待验证假设」

## 原则

> 公开的是**可迁移的工程知识**，不是公司资产。
