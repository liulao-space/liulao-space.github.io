本页导航

课程大纲

第一个模块。滚动页面，当它的顶部越过吸顶头部（getBoundingClientRect().top - offsetTop <= 0）时，左侧对应项会高亮。

点击左侧「课程大纲」，会通过 scrollIntoView({ behavior: 'smooth' }) 平滑滚回这里；配合 scroll-margin-top: 88px，标题不会被吸顶头部遮住。

知识宇宙

第二个模块。高亮逻辑是「取最后一个已经越过视口顶的 section」——所以滚动到这里时，左侧高亮会从「课程大纲」切到「知识宇宙」。

实现上只有一个滚动监听：window.addEventListener('scroll', onScroll, { passive: true })，每帧遍历导航项对比位置，最后统一写入一个 activeKey，渲染层只做一次对比。

能力图谱

第三个模块。注意每块 section 都有 id，它就是侧栏按钮的 data-key——这是「key = id」的隐式契约，页面与导航靠命名约定对齐。

如果某个 id 写错，点击会静默失效；一个稳妥做法是在 onMounted 时校验所有 key 都能 getElementById 到。

问题图谱

最后一个模块。滚动到底部回到顶部，高亮会依次退回。整个 demo 共一个 scroll 监听、四个 getBoundingClientRect 判断，没有其他逻辑。

关键三行：el.getBoundingClientRect().top - offsetTop <= 0 判定「已顶格」；scroll-margin-top 让出头部；{ passive: true } 避免阻塞滚动。

对应日志：一侧配置、一侧展示：双端并行开发 · 核心代码：activeKey 单值状态 + onScroll 遍历取最后顶格项 + scrollIntoView({behavior:'smooth'}) · offsetTop = 88 由「头部 64 + 间距 24」算出，可作 prop 注入。
