这里是教学版占位文案，演示五种纯 CSS 动效如何叠加。

五种关键帧：breathe（呼吸 4.5s）· halo-rotate（光环自转 14s）· aurora-sweep（极光扫光 9s）· particle-float（8 粒子错峰 6~8s）· enter-up（入场 stagger，由 --enter-delay 控制）
要点：所有动效只作用于 transform / opacity，避免 layout 重排；粒子用写死的 left/top + delay 而不是 JS 随机，保证 SSR 前后一致。
