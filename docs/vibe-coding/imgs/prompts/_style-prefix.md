# Shared style (warm notebook)

Aesthetic: premium digital notebook illustration, GoodNotes + Notion hybrid.
Warm cream paper background #FBF8F3 with subtle light gray dot grid.
Soft multi-layer drop shadows, pastel sticky notes (amber, mint, sky blue).
Slightly tilted sticky notes (1-3 degrees), rounded cards, generous whitespace.
Accent blue #3E94FF. Clean Chinese sans-serif labels. Teaching names only: learnspace, apps/admin, apps/www.
No watermark, no logos, no company brands, no photorealistic hands.
Flat refined vector look, 16:9 blog diagram, high polish.
