## 这个站是干什么的

我在用 AI 辅助日常开发（vibe coding）。为了避免「写了很多代码，自己却说不清改了啥」，我会把有价值的改动整理成日志：

1. **发生了什么**（结构 / 关键决策）
2. **用到了哪些知识**
3. **如果从零重来，有没有更好解法**
4. **我自己的检查清单**

所有内容默认按 [公开边界](/meta/disclosure) 脱敏后再发布。
